## 1. Overview
iCount is a cloud invoicing and financial bookkeeping platform in Israel.
- **Documents Supported:** Tax Invoices (`inv`), Receipts (`rec`), Invoice-Receipts (`invrec`), Credit Notes (`cinv`).
- **PDF Generation:** Encrypted PDF download links provided for each transaction.
